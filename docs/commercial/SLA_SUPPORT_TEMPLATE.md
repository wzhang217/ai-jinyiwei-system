# AI锦衣卫 SLA 与售后模板

## 服务等级

| 等级 | 定义 | 首次响应 | 临时措施 | 目标恢复 |
| --- | --- | ---: | --- | ---: |
| P0 | 服务不可用、跨租户数据风险、持续错误采集 | `[填写]` | 关闭代理入口/停用账号/回滚版本 | `[填写]` |
| P1 | 主要功能不可用、Agent 大面积离线或摘要持续失败 | `[填写]` | 切换备用服务、暂停 AI 或重试队列 | `[填写]` |
| P2 | 单设备异常、页面错误或非关键功能故障 | `[填写]` | 收集诊断包并安排修复 | `[填写]` |

## 客户报障最少信息

- 客户组织 ID、联系人和影响范围
- 服务端 `/health/ready` 结果和发生时间（东八区）
- Agent 版本、Windows 版本、设备 ID 和托盘状态
- 是否存在离线队列、上传错误或最近策略变更
- 脱敏诊断包；不得上传键盘、剪贴板、截图、聊天正文或文件正文

## 处理流程

1. 记录工单、影响范围、发现时间和当前版本。
2. P0/P1 先保护数据和服务：停用账号/设备、关闭外部入口或回滚签名 MSI。
3. 使用 `server` 的 healthcheck、diagnostics、backup 和 restore-check 工具定位。
4. 修复后验证健康检查、权限隔离、队列补传、AI 额度和审计链。
5. 关闭工单前记录根因、受影响数据范围、修复版本和客户确认。
