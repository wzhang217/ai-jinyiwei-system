## 处理边界

服务提供方只处理为活动元数据、设备运行、权限、审计和汇总所必需的数据。默认禁止处理键盘、剪贴板、屏幕、聊天正文、文件正文、原始窗口标题和完整 URL。Qwen/百炼仅接收脱敏的活动元数据；客户必须在合同和部署配置中明确是否允许将脱敏元数据发送给外部模型供应商，或者关闭 AI 外发并使用规则摘要。

## 安全控制确认

- [ ] 服务端使用 HTTPS，8787 不直接暴露公网。
- [ ] 客户配置独立组织、老板账号、JWT 密钥和最小权限。
- [ ] 生产关闭 bootstrap Token。
- [ ] 数据库和备份使用客户认可的加密存储及访问控制。
- [ ] 每日备份、异地保留和恢复演练已记录。
- [ ] Agent MSI 使用受信任的 Windows 代码签名证书。
- [ ] 客户确认员工告知、策略版本和确认记录流程。
- [ ] 导出、删除和事件响应联系人已确定。

## 事件与退出

双方约定安全事件通知时限、证据保全、协查方式、数据返还/删除、备份清理和服务终止后的账号吊销。删除和导出操作保留不可篡改审计记录，但不保留已删除活动的正文或原始采集内容。
