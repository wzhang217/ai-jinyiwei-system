# AI锦衣卫员工活动数据采集说明（交付模板）

> 这是交付模板，不是法律意见。上线前由客户法务、信息安全和人力负责人根据所在地法律、员工代表协商和企业制度审核后发布。

## 1. 目的与范围

AI锦衣卫用于把员工电脑上的有限活动元数据整理为个人和团队工作上下文，帮助员工回顾工作、帮助管理者查看经授权的工作主题和系统运行状态。系统不以应用切换次数直接推断绩效、薪酬或纪律结论。

## 2. 采集内容

默认采集：前台应用/进程名称、活动区间、系统空闲状态、有限的脱敏工作标识、浏览器网站域名、设备心跳、同步状态和策略确认记录。

默认不采集：键盘内容、剪贴板、屏幕截图、聊天正文、邮件正文、文件正文、原始窗口标题、完整 URL、查询参数和页面内容。浏览器来源只保留域名和允许的结构化提示。

## 3. 权限与可见范围

- 员工：查看本人活动、本人 Memory Summary、采集策略和隐私说明。
- 高管：查看直属团队的汇总、活动区间和设备状态。
- 老板：管理企业、账号、设备、策略、审计和全企业范围数据。

所有权限由服务端会话和组织范围强制执行，前端角色显示不是授权依据。系统不设置“审计员”业务角色。

## 4. 本地缓存与传输

网络中断时，Agent 会在员工电脑本地队列保存待同步元数据，恢复网络后按事件 ID 幂等补传。正式部署使用 HTTPS；客户应按自己的密码、密钥、备份和终端安全策略保护服务端与设备。

## 6. 版本与确认

每个组织发布隐私策略版本和哈希。Agent 在首次注册、策略版本变化或重新安装后要求员工确认；未确认前不新增或上传活动事件。客户应保存生效日期、通知记录和法务审批记录。
