## 合同必须明确

- 采集范围仅限已发布策略；键盘、剪贴板、截图、聊天正文、文件正文和完整 URL 不属于默认采集范围。
- 客户负责员工告知、劳动与隐私合规审批、账号生命周期和终端网络条件。
- 交付方负责版本发布、缺陷修复、备份工具和约定 SLA 内的支持。
- 数据删除、导出、留存和合同终止后的销毁时间必须明确。
- AI 输出是基于活动元数据的辅助总结，不作为自动绩效、纪律或劳动争议的唯一依据。
- 代码签名证书、API Key、JWT 密钥、客户数据和注册码不得进入 Git 仓库或 MSI。
